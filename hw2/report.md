Постановка задачи

При обучении нейронной сети разные изображения могут приносить неодинаковую пользу. Одни примеры сеть быстро распознаёт правильно, другие долго остаются сложными. Авторы статьи [1] исследуют, можно ли заметить это различие в начале обучения и заранее выбрать небольшую, но полезную часть данных. В работе используется исправленная вторая версия статьи, опубликованная в 2023 году.

**Обучающая выборка** - изображения, по которым сеть учится распознавать классы. **Проверочная выборка** - отдельные изображения, используемые для оценки качества. **Точность распознавания** - доля правильных ответов на проверочной выборке. Разделение этих данных позволяет оценивать работу сети на примерах, не участвовавших в обучении и отборе.

В данной работе сравниваются два способа выбрать половину обучающей выборки: случайный отбор и отбор по оценке, предложенной в статье. Для каждого способа предусмотрены четыре независимых обучения. Итоговой сети на всех данных в согласованном опыте нет. Поэтому проверяется преимущество одного способа отбора перед другим; утверждение о сохранении точности относительно полного набора напрямую не проверяется.

Оценка полезности изображения

Сеть выдаёт вероятности принадлежности изображения каждому классу. Правильный ответ записывается вектором, в котором единица соответствует нужному классу, а остальные элементы равны нулю. **Оценка ошибки вероятностей** - расстояние между этими двумя векторами: квадратный корень из суммы квадратов разностей. Авторы обозначают её EL2N.

Для каждого изображения сначала вычисляются оценки десяти предварительно обученных сетей, затем берётся их среднее. Усредняются именно расстояния, а не вероятности классов. Изображения с наименьшей средней оценкой удаляются, а новая сеть обучается с нуля на оставшейся половине. Высокая оценка может означать как сложный пример, так и ошибочную метку; сама по себе она не гарантирует полезность.

В нашей проверке остаются только два способа отбора половины.

**ResNet-18** - нейронная сеть с восемнадцатью слоями и связями между блоками, облегчающими обучение. Её архитектура взята без изменений из кода авторов [2]. **Шаг обучения** - одно обновление весов сети по порции изображений. **Эпоха** - проход по обучающей выборке.

| Условие | Значение |

| Предварительные сети | 10 сетей; 50 000 изображений; 7 800 шагов |

| Итоговые сети | 2 способа × 4 повторения; по 25 000 изображений |

| Длительность итогового обучения | 78 000 шагов; порция из 128 изображений |

| Среда вычислений | Google Colab, NVIDIA Tesla T4 |

В статье длительность отсчитывается относительно полной выборки: 390 шагов соответствуют почти одной эпохе. После отбора число шагов сохраняется. Поэтому 78 000 шагов означают около 400 проходов по половине данных. Всего предусмотрено 702 000 шагов. Уменьшение выборки здесь не доказывает двукратное сокращение вычислений.

Выполненное предварительное обучение

В сохранённом снимке завершены 8 из десяти предварительных сетей. Каждая прошла 7 800 шагов на всех 50 000 обучающих изображениях. Ошибка обучения - среднее значение отрицательного логарифма вероятности правильного класса. Чем увереннее верный ответ сети, тем меньше эта ошибка.

![Рис. 2. Ошибка предварительных сетей в зависимости от числа шагов. График построен по журналам Colab.](results/figures/preliminary_training.png)

К последнему шагу ошибка лежит в диапазоне от 0.368 до 0.392. Убывающие кривые подтверждают выполнение обучения. Они не показывают точность на новых изображениях и не доказывают преимущество отбора. После восстановления повторные записи одного шага заменены последней записью; пропуски не заполнены искусственными значениями.

Средняя по всем изображениям оценка равна 0.273. Значения конечны и находятся в допустимом диапазоне от нуля до квадратного корня из двух. До окончания десяти предварительных обучений среднее остаётся промежуточным: оно не подменяет оценку, по которой выполняется итоговый отбор.

Согласованность оценок разных сетей

**Ранговая корреляция Спирмена** измеряет сходство двух упорядочений. Значение, близкое к единице, означает похожий порядок изображений; значение около нуля означает отсутствие линейной связи между их рангами. Здесь сравниваются порядки, заданные оценками разных предварительных сетей. Одинаковые оценки получают средний ранг.

Рис. 4. Попарная ранговая корреляция оценок на всех обучающих изображениях.

![Рис. 4. Попарная ранговая корреляция оценок на всех обучающих изображениях.](results/figures/score_agreement.png)

Вне главной диагонали значения лежат между 0.43 и 0.71. Оценки разных сетей согласованы лишь частично. Это наблюдение объясняет смысл усреднения нескольких сетей, однако не устанавливает, что выбранные изображения дадут лучшую итоговую точность. График служит самостоятельной проверкой устойчивости оценивания и не является копией численного результата статьи.

Проверка реализации и происхождение данных

В Colab прошли проверки формулы оценки, обновления весов, расписания, порядка порций и точного продолжения после сохранения. Архитектура авторов и программа закреплены контрольными суммами. Сохранение первой сети после 3 900 шагов перенесено из прежнего запуска с проверкой параметров; происхождение записано в checkpoint_import.json. Первые шаги отсутствуют в новом журнале, поэтому соответствующий участок кривой не дорисован.

Среда отличается от исторической: Python 3.13.15, JAX 0.11.1, Flax 0.12.10 и NumPy 2.1.3. Используются стандартный архив CIFAR-10 вместо порядка TensorFlow Datasets и другие генераторы случайного перемешивания. Обработка изображений и формула обновления весов сохранены. После переполнения Google Диска рабочие файлы перенесены в память Colab, а проверенные резервные копии - на локальный диск E.

Итоговое сравнение

**На момент снимка итоговых обучений завершено 0 из восьми. Вывод о преимуществе отбора пока не получен.** После окончания будут независимо проверены 78 000 шагов каждого обучения, 25 000 уникальных индексов, среднее оценок десяти сетей и точность, пересчитанная из сохранённых вероятностей для 10 000 проверочных изображений.

Для каждого способа рассчитываются средняя точность, выборочное стандартное отклонение и 16-й и 84-й процентили. Стандартное отклонение описывает разброс повторений; процентиль - значение, ниже которого находится заданная доля результатов. Такой промежуток соответствует способу показа разброса в статье и не является доверительным интервалом. Даже положительная разность средних проверит только сравнение двух половин, поскольку результата полного набора здесь нет.
