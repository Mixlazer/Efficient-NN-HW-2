### Experiment

EL2N is the Euclidean distance between predicted class probabilities and the one-hot correct answer. We average **ten separate distances** for each training image and retain the 25,000 highest-scoring images.

| Stage | Agreed configuration |
|---|---|
| Preliminary scoring | 10 ResNet-18 networks; all 50,000 CIFAR-10 training images; 7,800 updates each |
| Final comparison | Random 25,000 images vs. EL2N-selected 25,000 images |
| Repetitions | 4 per method, paired initial weights; 78,000 updates each |
| Evaluation | All 10,000 test images, evaluated after the last update |
| Compute | Google Colab, NVIDIA Tesla T4, float32 |

The full-data final baseline is intentionally omitted. Therefore this experiment can compare selection methods, but cannot directly verify accuracy preservation relative to training on all 50,000 images. Keeping the update budget also means that halving the dataset does not establish a twofold compute reduction.

**Обучающая выборка** — изображения, по которым сеть учится. **Проверочная выборка** — отдельные изображения для оценки точности. **Точность** — доля правильных ответов. Набор CIFAR-10 содержит 50 000 обучающих и 10 000 проверочных изображений, разделённых на десять классов.

**Оценка ошибки вероятностей**, в статье обозначенная EL2N, — расстояние от предсказанных вероятностей классов до вектора правильного ответа. У нужного класса в таком векторе стоит единица, у остальных — нули. Для каждого изображения усредняются расстояния десяти предварительно обученных сетей. Итоговый отбор сохраняет 25 000 изображений с наибольшей средней оценкой.

Сравниваются случайная половина данных и половина, выбранная методом статьи. Для каждого способа предусмотрены четыре обучения по 78 000 шагов. Шаг — одно обновление весов по порции из 128 изображений. Предварительные сети обучаются на всех 50 000 изображениях по 7 800 шагов. Архитектура ResNet-18 взята без изменений из кода авторов; вычисления выполняются на Tesla T4 в Colab.

### Графики по сохранённым измерениям

![Распределение оценок обучающих изображений](hw2/results/figures/score_distribution.png)

Среднее здесь получено по восьми завершённым сетям. Оно промежуточное и не используется вместо среднего десяти сетей для итогового отбора. Гистограмма показывает распределение оценок, но не доказывает преимущество метода.

![Примеры изображений с низкими и высокими оценками](hw2/results/figures/image_examples.png)

Примеры автоматически выбраны по крайним оценкам среди 100 случайных изображений каждого класса. Высокая оценка может указывать на сложное изображение или ошибочную подпись. Польза отбора проверяется отдельным обучением, а не внешним сходством иллюстраций с рисунками статьи.

Обучения на полном наборе нет, поэтому сохранение точности относительно всех 50 000 изображений напрямую не проверяется. Это ограниченное воспроизведение сравнения способов отбора. По окончании всех повторений точности пересчитываются из сохранённых вероятностей; затем вычисляются средние, выборочные стандартные отклонения и 16-й и 84-й процентили.
